Instructions

  • Click on the map, drag an existing marker on the map, or enter a coordinate into the Latitude and Longitude boxes to move the active coordinate.
  • Click markers on the map or the coordinate numbers at the bottom of the screen to switch between coordinates.
  • You can remove the active coordinate from the selection.
  • Click the folder icon to import an existing basin outline in KMZ format to help with coordinate selection.
  • Submit the coordinates to find the nearest set of IDF curves. An average set of IDF curves will be returned for a selection of multiple coordinates.

Instructions

  • Cliquez sur la carte, faites glisser un marqueur existant sur la carte ou entrez une coordonnée dans les zones de Latitude et de Longitude pour déplacer la coordonnée.
  • Cliquez sur les marqueurs sur la carte ou les numéros de coordonnées au bas de l'écran pour basculer entre les coordonnées.
  • Vous pouvez supprimer la coordonnée de la sélection.
  • Cliquez sur le bouton de dossier pour importer un schéma de bassin existant au format KMZ pour aider à la sélection de coordonnée.
  • Soumettre les coordonnées pour trouver l'ensemble des courbes IDF. Une moyenne sera retournée pour une sélection de plusieurs coordonnées.
